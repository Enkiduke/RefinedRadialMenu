# Refined Radial Menu

A secure radial action menu for World of Warcraft Retail. Hold a key, point at a slot, release to use it. Works in combat.

Split out from the RadBar module of RefineUI.

## Usage

- **Open:** hold the **Open Radial Menu** keybind (Key Bindings → Refined Radial Menu). F8 is assigned on first load if it's free.
- **Use:** point at a slot and release the key. Releasing near the middle uses the center slot.
- **Close without using:** right-click.

The ring has four outer slots and a center slot. Each holds a spell, item, macro, or mount.

## Customizing

Changes are made out of combat.

- **Add:** pick up a spell, item, macro, or mount. The ring appears at the center of the screen; drop it on a slot.
- **Move out:** Shift-drag a slot's icon to pick it up.
- **Remove:** with the ring open, hold Ctrl or Shift over a slot (a red X appears) and right-click.

## Slash commands

| Command | Action |
|---|---|
| `/radial`, `/rrm` | Toggle the ring |
| `/rrm reset` | Clear every slot |

## Install

Copy the `RefinedRadialMenu` folder into `World of Warcraft\_retail_\Interface\AddOns\`.
