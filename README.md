# Refined Radial Menu

![Refined Radial Menu in action](Media/Preview/RefinedRadialMenu.gif)

A simple secure radial menu for World of Warcraft. Drag and drop abilities. Hold a key, point, let go. Works in combat.

Bind it under **Key Bindings → Refined Radial Menu** (it grabs F8 if nothing else is using it).

To fill a slot, drag a spell, item, macro, or mount onto the ring. To clear one, hold Ctrl or Shift over it and right-click.

That's it.
